## الإصدار 1.0.0 — الإصدار الأول

- التوأم الرقمي لمصنع تصنيع مجاري الهواء (Duct) بنموذج ثلاثي الأبعاد ومحاكاة خط الإنتاج والمؤشرات (OEE، الإنتاجية، الهدر، الطاقة).

- مختبر تصميم الدكت (طريقة السرعة والاحتكاك المتساوي، القطر المكافئ، اختيار السماكة، الوزن والتكلفة).
- مكتبة تعليمية ثنائية اللغة (عربي/إنجليزي) ودليل مصانع الدكت في الوطن العربي وبيانات مناخ التصميم.
- اختبارات تقييم مع تصدير النتائج (CSV/JSON/PDF) ولوحة مشرف لمتابعة الطلاب.
- نظام تراخيص موقّع رقمياً (مدى الحياة / محدد المدة) وتحديثات تلقائية.

## Version 1.0.0 — first release

- Factory Digital Twin with a 3D duct-factory model, production-line simulation and KPIs (OEE, throughput, scrap, energy).
- Building duct-network Digital Twin: pressure, velocity, leakage and heat-gain calculations with live controls.
- Duct Design Lab (velocity / equal-friction sizing, equivalent diameter, gauge selection, weight and cost).
- Bilingual learning library (Arabic/English), Arab-world duct-factory directory and climate design data.
- Assessments with CSV/JSON/PDF export and a supervisor dashboard for student tracking.
- Digitally signed licenses (lifetime / time-limited) and automatic updates.
